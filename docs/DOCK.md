# The dock

Moved out of [CLAUDE.md](../CLAUDE.md) so it loads only when you work on this area. CLAUDE.md keeps the rules that bite from anywhere else; read them there too.

A pinned **live strip** that folds to one line (names, score, and ⇆ Sides · ⇄ Ports · Report · Stats in Doubles' place; remembered in `localStorage`) — both sides' names, characters via a select-screen picker (tap sets, hold/right-click opens costumes, **None** in the grid's last slot clears), score ±, round / best-of / [L] overrides with Auto text, ⇆ Sides · ⇄ Ports · ↻ Detect · Start · Report · **Stats** (the stats popup up or down), and Clear score · Clear set — over nine tabs: **Set · Bracket · Stats · Casters · Players · Clips · Replays · Crew · Setup**. The tab bar shows the ones picked on **Setup → Tab bar**, in the order set there (↑ ↓; default Set, Bracket, Stats, Casters, Players; per device, `localStorage` `dock.tabbar`, drawn with flex `order`) and puts the rest in a **More** dropdown, which shows the open tab's name lit while it's one of them. Fed by the `/dock` namespace's state plus `status`. Fonts (Saira, Martian Mono) are self-hosted — venue Wi-Fi is unreliable.

- **The strip's modes.** A **Doubles** toggle (`/api/doubles`) gives each side two players, one line each (tag only — the overlay shows no prefixes in doubles), and swaps the characters for a red/blue/green **team colour** picker (`/api/side-color`) under them — the overlay shows the colour, not four icons. **Start and Report exist only for a set loaded from start.gg** (`setId`); a manual set has none. **Changing a tag or prefix on the strip (typed or picked) unlinks the set** (`store.detachSet()`: set id, entrants, seeds, team name) — capitalisation alone doesn't, nor does a Players-tab edit; reload the set from Up next to relink. The side bars are violet (left) and yellow (right), deliberately none of Melee's team colours.
- **The Crew tab** drafts two crews (kept in `localStorage`, with Load/Save/✕ against the saved crews; tags suggest from the whole player list) and starts the battle, asking first over a set with games; during one it is the live rosters — **In** sends a player in, −/+ per member, tag/name edits, ↑ and ✕ go straight to `/api/crew/roster` — and End. Roster rows are rebuilt only when the member ids change, so a push can't take the focus from a tag. **The strip in a crew battle** (`#strip.crew`) shows each crew's name over the player in (a tap opens the tab), their character and the crew's stocks, ± off with nobody in; Doubles, best-of, [L] and the clear keys go, and a lit **Crew** chip takes Doubles' place. A load from Up next during one asks first. `crew:notice` is a toast.
- **The Bracket tab** picks the view (five bracket views and **Up Next**) and group, and points the overlay (`/api/bracket-camera`): **Auto** (the tour), ◀ ▶, a key per page (its `short` label), **◎ Live**; then the Board — a D-pad, −/+, Overview, and a minimap of the pruned board (drawn with the overlay's own `layout.js`, so a tap's `goto` lands where the overlay will look) boxing the camera, or the page up. No global hotkeys for any of it.
- **Every card folds to its header line** (`foldable()`; `data-fold="<key>"` on a static card, a call for the built ones — the crews, the live rosters, each Replays set), remembered per key in `localStorage` (`dock.folds`). Folded, a card keeps its label, a one-line `.fold-sum` its render keeps current, whatever else its header holds (badges, the clipper's switch) and its `.fold-only` keys; `.open-only` header parts go. **A folded key is a proxy** (`data-proxy="<id>"`): it clicks the real key and `syncProxies()` — run after every `guard()`ed render — copies its `disabled`, `gone`, `lit` and title, so there is one handler and one set of rules. The folded strip's ⇆ ⇄ Report are proxies too; `#report-confirm` and `#clear-confirm` sit outside the strip's body so Report asks in place, and `confirmIn()` opens a folded card before asking in it.
- **Tooltips are the dock's own** (`tooltips()`, `#tip`): OBS's dock browser cuts native ones off. A hovered element's `title` moves to `data-tip` and back when the pointer leaves, so code reading `.title` sees what it set; mouse only.
- **No `innerHTML`**: nodes are built with `Overlay.h()`. **Every renderer is wrapped in `guard()`**, so one that throws shows in the dock instead of freezing it. `tests/dock-static.test.js` checks every id the script looks up exists and every route it calls exists with that method.
- **Input survives pushes.** A name being typed isn't overwritten mid-word (commits on change; Escape sends nothing); the casters are a **draft until Put on stream**, kept across pushes unless unchanged and nobody is typing; the clipper form is generated from one `CLIP_FIELDS` spec and latches dirty.
- **Health:** `control_status` is sent on change plus a **5s heartbeat**; no status for ~12s dims the lights.
- **Setup → Art packs** lists the stats popup's art packs (installed version, size) and downloads every missing or outdated one in one click, with a progress bar. The Stats tab lists **only what's downloaded** (Portraits reads "None downloaded" with none, and offers Random poses only with a full-body pack); stage pictures have no setting — they show when a stage set is installed. The Stats tab is dropdowns and toggles: **Layout** (or **Auto**: a layout from the Layouts table's ticks at each show, picked once by `director.js` into `statsShot.layout`), **Reads** (Auto, Last game, Wrap-up or **Random**: either one, picked at each show), **Look** — **Best fit** (style and pack `auto`: each layout's saved combo, else its recommended one, so Auto draws every layout in its own) or **Manual** (a Style and Portraits picked for every layout — Style can stay **Best fit**, each layout's own, or be **Random**, one per show; Portraits can be **Random poses**, `pack: "random"`, see `portraits.js`; **★ Save** makes them the drawn layout's best fit, `statsConfig.combos`, random included; **Forget** drops it) — Wait and Hold, and an **Auto** switch in the header.
- **The Stats tab's Layouts table** (its own foldable card, under the main one) is a row per layout: its look — the saved combo (★, ↺ back to the recommended one) or its recommended one — with a **Style** and a **Portraits** pick that write `combos` (the same thing the card's ★ Save writes; picking the recommended look again drops it), and two ticks, **Mid-set** and **Over** (`statsConfig.pools.mid` / `.over`): the layouts Auto draws while the set is on and once it's won. A phase keeps at least one. A layout picked by hand on the card takes Auto off — the table dims and says so, with **Use Auto** to put it back.
- **The Set tab's Best-of card** is the best-of rule (`setRules`): the format before the switch, where it switches (top 3–16 or never) and the format after; the strip's Auto shows what it gives this set, and a best-of picked on the strip still wins.
- **The Players tab's Event roster** (above the player list; read when shown open) lists the loaded event's entrants by seed with the main each one's sets open on (`/api/players/event`); a tap opens the picker to set it (`/api/players/main`, the player's stored main — what Slippi has learned still wins). An entrant not in the DB is found by start.gg id (`{ playerId }`), which adds them as their first set load would. "No main only" is a client-side filter. A main is for the next load — the set on air keeps its character.
- **Autocomplete** (`autocomplete()` in `dock.js`, one shared `#ac-menu`, not a `<datalist>`) on the round, prefix, tag, pronoun and caster fields. The strip's tag suggests the **loaded event's entrants only** (the whole player DB with no event), and a pick fills the slot through `/api/players/assign`. A field's own keydown handler goes after `autocomplete()` and skips a `defaultPrevented` key, or Enter on a suggestion also commits the typed text.
- Report and a load over a set with games ask first. The active tab and Up next's **Hide waiting** (a client-side filter; the on-air set is never hidden) persist in `localStorage` (wrapped — it can throw).
- Layout: one column in an OBS dock, more from ~760px; usable from a phone. `lan-urls.js` lists the dock's url on every reachable address, **Tailscale (`100.64/10`) first** — it survives a venue network change and guest Wi-Fi client isolation; Hyper-V switches and `169.254` adapters are filtered out.
